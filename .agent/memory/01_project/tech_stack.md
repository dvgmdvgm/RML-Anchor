## 📊 Stack Overview

| Layer | Technology | Purpose |
|-------|------------|---------|
| **Storage** | Markdown (.md) | Human-readable knowledge storage |
| **Structure** | File system folders | Category organization |
| **Scripts** | Python 3.x | Validation, stats, search utilities |
| **Version Control** | Git | Change tracking, collaboration |

## 📝 Primary Technologies

### Markdown

| Aspect | Details |
|--------|---------|
| **Why** | Human-readable, AI-native, Git-friendly |
| **Format** | GitHub-flavored Markdown |
| **Extensions** | Tables, emoji, code blocks |

### Python Scripts

| Script | Purpose |
|--------|---------|
| `memory_validate.py` | Validate memory structure |
| `memory_stats.py` | Generate statistics |
| `memory_search.py` | Search across memory |

| Technology | Why Not |
|------------|---------|

| Cloud storage | Privacy concerns |
| Binary formats | Can't be edited manually |
| Proprietary APIs | Causes lock-in |
