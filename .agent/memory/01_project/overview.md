## 🎯 What is RLM-Anchor?

RLM-Anchor (AnchorGravity) is a **persistent memory system** for AI-powered development environments. It solves the problem of context loss in AI assistants by providing structured, file-based memory that persists across sessions.

## 🌟 Core Features

| Feature | Description |
|---------|-------------|
| **13 Memory Categories** | Structured storage for all project knowledge |
| **RLM-like Search** | Examine → Decompose → Recurse → Aggregate |
| **Multi-language** | 11 languages supported |
| **Simple Commands** | `/wakeup`, `/sleep`, `/remember`, `/recall` |
| **Session Persistence** | Context preserved between sessions |
| **Markdown-based** | Human-readable, Git-friendly |

## 📈 Project Goals

1. **Eliminate context re-teaching** — AI should remember what was discussed
2. **Preserve decisions** — Architecture decisions (ADRs) are never lost
3. **Enable handoffs** — Switch AI models without losing context
4. **Stay simple** — No databases, no complex setup
5. **Stay open** — MIT license, no lock-in
