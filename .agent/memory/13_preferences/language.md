## 🔄 How to Change Language / Как изменить язык

Simply change the `LANGUAGE=` value above to your preferred language code.

Просто измени значение `LANGUAGE=` выше на код желаемого языка.

**Example / Пример:**
- For English: `LANGUAGE=en`
- Для испанского: `LANGUAGE=es`
- Für Deutsch: `LANGUAGE=de`
