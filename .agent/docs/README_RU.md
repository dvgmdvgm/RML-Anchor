## 📝 Примеры использования

### Начать работу:
```
Пользователь: /wakeup

AI: 🚀 Загружаю контекст проекта...
    ✅ Сессия начата!
    📌 Незавершённых задач: 2
    💡 Чем займёмся?
```

### Запомнить решение:
```
Пользователь: /remember мы выбрали PostgreSQL для транзакций

AI: ✅ Записано в memory/03_decisions/ADR-002-database.md
```

### Вспомнить информацию:
```
Пользователь: /recall почему выбрали PostgreSQL?

AI: 📁 Найдено в памяти:
    Источник: memory/03_decisions/ADR-002-database.md
    Мы выбрали PostgreSQL для поддержки ACID транзакций...
```

### Завершить работу:
```
Пользователь: /sleep

AI: 📝 Суммаризирую сессию...
    ✅ Сессия завершена!
    📁 Сохранено в историю
    👋 До встречи!
```

## 🛡️ Безопасная интеграция в существующий проект

### Команда: `/agent`

Эта команда проверяет конфликты перед интеграцией:

```
Пользователь: /agent

AI: 📋 АНАЛИЗ ИНТЕГРАЦИИ
    
    ✅ Безопасно для добавления:
    - memory/ (новая папка)
    - MEMORY_INDEX.md
    
    ⚠️ Потенциальные конфликты:
    - workflows/remember.md (уже существует!)
    
    Выбери вариант:
    1. [SAFE] Только неконфликтующие файлы
    2. [MERGE] Слить с существующими
    3. [FULL] Полная установка (с бэкапом)
    4. [CANCEL] Отменить
```

## ⚠️ Важные правила

### Язык:
- **ВСЕГДА** проверяй `language.md` в начале сессии
- **ВСЕГДА** отвечай на настроенном языке
- **НИКОГДА** не переключайся на язык пользователя если он отличается от настройки

### Память:
- Записывай **только значимую** информацию
- **Обновляй индексы** при создании файлов
- **Ссылайся на источники** в ответах

### Триггеры:
- Слова "почему", "решили", "проблема" → проверь память
- Слова "запомни", "важно" → предложи записать
