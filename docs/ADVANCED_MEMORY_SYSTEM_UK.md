## 🎯 Проблеми, які вирішуємо

### Проблема 1: Накопичення сміття
**Симптом**: З часом пам'ять заповнюється застарілими, дублікатами або нерелевантними даними.

**Реальний приклад**: Ти записав "Ми використовуємо React 17", потім оновились до React 18, але старий запис залишився. AI може дати застарілу пораду.

**Рішення**: TTL + Importance Score + Periodic Cleanup

---

### Проблема 2: Занадто багато ручної роботи
**Симптом**: Користувач втомлюється вручну зберігати кожен важливий факт.

**Рішення**: Автоматичне збереження за шаблонами

## ⏳ TTL (Time-to-Live)

Кожен запис має "термін придатності". Не для автовидалення, а для **позначки на ревью**.

| Категорія | TTL | Причина |
|-----------|-----|---------|
| `current_session.md` | 1 день | Актуально тільки сьогодні |
| `session_history/` | 30 днів | Історія застаріває |
| `workarounds/` | 90 днів | Workaround'и мають стати fix'ами |
| `03_decisions/` | 365 днів | Рішення можуть переглядатися |

## ⭐ Importance Score

### Формула:

```
Importance = Base × Recency × Access × Explicit

Де:
- Base = базова вага категорії (ADR=0.9, session=0.3)
- Recency = 1 / (днів з моменту створення + 1)
- Access = log(access_count + 1) / 10
- Explicit = 1.5 якщо користувач явно позначив як важливе
```

### Пороги:

| Score | Статус | Дія |
|-------|--------|-----|
| > 0.7 | 🟢 Критична | Ніколи не видаляти |
| 0.4-0.7 | 🟡 Важлива | Summarize при очищенні |
| 0.2-0.4 | 🟠 Середня | Архівувати через TTL |
| < 0.2 | 🔴 Низька | Кандидат на видалення |

## 🧹 Periodic Cleanup

Автоматичне очищення запускається:
1. **При `/wakeup`** — швидка перевірка
2. **При `/sleep`** — повна перевірка
3. **Вручну** — `/anchor_cleanup`

## 📝 Summarization

Замість повного видалення старих даних — **стиснення в резюме**.

| Тип | Коли застосовується | Результат |
|-----|---------------------|-----------|
| **Session Merge** | Декілька сесій за період | 1 файл з ключовими пунктами |
| **Topic Compress** | Багато записів на одну тему | 1 структурований файл |
| **Archive Summary** | Перед архівуванням | Metadata + 1 абзац |

## ✅ Підсумок

Ця система перетворює "наївну" пам'ять на **self-maintaining knowledge base**:

- 🤖 **Автоматизація** — важливе зберігається само
- ⏳ **Управління часом** — старе не забувається, а стискається
- 🧹 **Чистота** — сміття видаляється, але з backup
- 🔐 **Безпека** — нічого не втрачається назавжди
- 📦 **Портативність** — легко перенести на інший ПК
