## 🎯 Обзор V2.0

V2.0 состоит из **4 Python-скриптов**, которые расширяют возможности AI-агента по управлению памятью:

| Скрипт | Задача | Строк кода |
|--------|--------|------------|
| `memory_summarize.py` | Анализ, сжатие, архивация | ~1000 |
| `memory_search.py` | Поиск с нечётким совпадением | ~380 |
| `memory_validate.py` | Проверка целостности | ~370 |
| `memory_stats.py` | Визуальная аналитика | ~370 |

### Ключевые принципы

- **0 зависимостей** — только стандартная библиотека Python
- **Автономность** — скрипты работают без AI, можно запускать вручную
- **JSON API** — каждый скрипт поддерживает `--json` для автоматизации
- **Dry-run** — опасные операции имеют режим предпросмотра
- **Windows-совместимость** — UTF-8 фикс для корректного вывода emoji

## 🧠 Скрипт 1: memory_summarize.py — Умная суммаризация

### Что делает

Анализирует ВСЮ память и даёт ответ: **что оставить, что сжать, что архивировать, что удалить**.

### Алгоритмы внутри

| Алгоритм | Как работает |
|----------|-------------|
| **Importance Score** | `Base × Recency × Access × Explicit`. Базовый вес категории × свежесть × объём контента × бонусы |
| **TTL Check** | Сравнивает возраст файла с настроенным TTL для каждой категории |
| **Session Merge** | Группирует сессии по месяцам, генерирует дайджест, архивирует оригиналы |
| **Topic Compress** | Jaccard similarity по ключевым словам между файлами — находит дубликаты |

### Все команды

```bash
# 📊 Полный отчёт (Importance Score + TTL + Sessions + Topics + Рекомендации)
python memory_summarize.py

# ⚡ Быстрая проверка в одну строку
python memory_summarize.py --scan

# ⭐ Только оценки важности (ранжированный список)
python memory_summarize.py --scores

# ⏳ Только просроченные записи
python memory_summarize.py --expired

# 📅 Только группы сессий
python memory_summarize.py --sessions

# 🏷️ Только тематические кластеры (дубликаты)
python memory_summarize.py --topics

# 🔄 Слияние сессий (показать план)
python memory_summarize.py --merge-sessions --dry-run

# 🔄 Слияние сессий (выполнить!)
python memory_summarize.py --merge-sessions

# 📦 Архивировать просроченные (показать план)
python memory_summarize.py --archive-expired --dry-run

# 📦 Архивировать просроченные (выполнить!)
python memory_summarize.py --archive-expired

# 🤖 JSON для AI-интеграции
python memory_summarize.py --json
```

## 🔍 Скрипт 2: memory_search.py — Умный поиск

### Что делает

Полнотекстовый поиск по памяти с **ранжированием по релевантности** и **нечётким совпадением** (устойчив к опечаткам).

### Алгоритмы внутри

| Алгоритм | Как работает |
|----------|-------------|
| **Exact Search** | Подстрока в каждой строке (case-insensitive) |
| **Fuzzy Search** | Расстояние Левенштейна со скользящим окном по словам |
| **Relevance Ranking** | Бусты: заголовок H1 ×3, H2 ×2, таблица ×1.5, имя файла ×4 |
| **Category Boost** | Решения ×1.3, Архитектура ×1.2, Контекст ×0.7 |
| **Multi-word** | AND (все слова на строке) или OR (любое слово) |

### Все команды

```bash
# 🔍 Точный поиск
python memory_search.py "запрос"

# 🔮 Нечёткий поиск (опечатки OK!)
python memory_search.py "markdwn" --fuzzy

# 🔑 Несколько слов — найти ВСЕ (по умолчанию, AND)
python memory_search.py "архитектура решение"

# 🔑 Несколько слов — найти ЛЮБОЕ (OR)
python memory_search.py "архитектура решение" --any

# 📁 Поиск в конкретной категории
python memory_search.py "TTL" --cat 13_preferences

# 📝 С контекстом (показать строки вокруг совпадения)
python memory_search.py "markdown" --context 3

# 🏆 Только топ-N результатов
python memory_search.py "запрос" --top 5

# 🔧 Комбинация: нечёткий + в категории + контекст
python memory_search.py "postgre" --fuzzy --cat 01_project --context 2

# 🤖 JSON для AI
python memory_search.py "запрос" --json
```

## ✅ Скрипт 3: memory_validate.py — Валидация

### Что делает

Проверяет **целостность** системы памяти: структуру, схему файлов, битые ссылки, пустые файлы, индексы — и выставляет **оценку здоровья в %**.

### 6 типов проверок

| Тип | Что проверяет |
|-----|--------------|
| **Structure** | Все 13 категорий, `_index.md`, шаблоны, подпапки, workflows |
| **Schema** | Заголовок H1, обязательные секции ADR (Контекст/Решение) |
| **Links** | Битые Markdown ссылки `[text](path)` и стрелочные `→ file.md` |
| **Content** | Пустые файлы, мало слов, шаблонные маркеры (TODO, TBD) |
| **Index** | Все ли файлы перечислены в `_index.md` своей категории |
| **Encoding** | UTF-8 кодировка всех .md файлов |

### Все команды

```bash
# ✅ Полная валидация (все 6 проверок)
python memory_validate.py

# 📁 Только структура
python memory_validate.py --structure

# 📋 Только схема (frontmatter, секции ADR)
python memory_validate.py --schema

# 🔗 Только битые ссылки
python memory_validate.py --links

# 📝 Только контент (пустые/шаблонные)
python memory_validate.py --content

# 📇 Только индексы (все ли файлы перечислены)
python memory_validate.py --index

# 🔤 Только кодировка
python memory_validate.py --encoding

# 🔧 Автоисправление (показать план)
python memory_validate.py --fix --dry-run

# 🔧 Автоисправление (выполнить!)
python memory_validate.py --fix

# 🤖 JSON для AI
python memory_validate.py --json
```

## 🤖 Интеграция с AI-агентом

Все скрипты поддерживают `--json`, что позволяет AI-агенту программно анализировать результаты:

### В workflow `/recall`

AI автоматически использует `memory_search.py` когда ручной поиск по индексам не даёт результатов (шаг 4.5).

### В workflow `/anchor_cleanup`

AI запускает `memory_summarize.py --json` для получения рекомендаций, затем:
- Если `summarize > 0` → предлагает Session Merge
- Если `archive > 0` → предлагает архивацию
- Если `delete > 0` → запрашивает подтверждение на удаление

### В workflow `/memory-stats`

AI запускает `memory_stats.py` и `memory_stats.py --snapshot` для отображения статистики и отслеживания роста.

TTL_RULES = {
