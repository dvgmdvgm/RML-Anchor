# 🧠 RLM-Anchor — Система памяти AI

> Дайте вашему AI-ассистенту **постоянную память**, которая сохраняется между чатами.

---

## 💡 Проблема

Каждый раз, начиная новый чат с AI, он забывает всё:
- Архитектуру проекта
- Прошлые решения и их причины
- Известные баги и обходные пути
- Ваш стиль написания кода
- Над чем вы работали вчера

**RLM-Anchor решает эту проблему.** Он даёт AI структурированную долгосрочную память — в виде простых Markdown-файлов прямо в вашем проекте.

---

## 🚀 Быстрый старт (3 шага)

### 1. Установка

```bash
git clone --depth 1 https://github.com/dvgmdvgm/AnchorGravity.git .temp && cp -r .temp/.agent . && rm -rf .temp
```

### 2. Установка языка

Отредактируй `.agent/memory/13_preferences/language.md`:
```
LANGUAGE=ru
```

### 3. Инициализация

Вставь в чат AI:
```
/anchor_agent проверь каталоги текущего проекта на наличие данных, которые помогут правильно выстроить контекст и настроить память (технические данные, бизнес модели, правила дизайна и все остальные типовые шаблоны для поиска и сохранения контекста проекта)
```

**Готово!** Теперь используй `/wakeup` для начала и `/sleep` для завершения каждой сессии.

---

## ⚡ Ежедневный рабочий процесс

```
/wakeup          → AI загружает контекст проекта
  ... работа ... → разработка, вопросы, решения
/remember ...    → сохранить важное в память
/sleep           → AI сохраняет сессию, можно закрывать чат
```

В следующий раз откроешь новый чат → `/wakeup` → AI помнит всё.

---

## 📋 Команды

| Команда | Что делает |
|---------|-----------|
| `/wakeup` | Начать сессию — загрузить память проекта |
| `/sleep` | Завершить сессию — всё сохранить |
| `/remember` | Сохранить факт, решение или заметку |
| `/recall` | Найти что-то в памяти |
| `/anchor_briefing` | Полный обзор проекта |
| `/anchor_update` | Обновить RLM-Anchor до последней версии |
| `/anchor_backup` | Создать резервную копию |
| `/anchor_restore` | Восстановить из бэкапа |
| `/handoff` | Создать сводку для переключения AI-моделей |
| `/memory-stats` | Показать статистику памяти |

## 🧩 Как это работает

```
Ваш проект/
├── src/                    ← ваш код (не изменяется)
├── .agent/                 ← память AI живёт здесь
│   ├── memory/
│   │   ├── 01_project/     ← информация о проекте
│   │   ├── 02_architecture/← архитектура системы
│   │   ├── 03_decisions/   ← почему выбрали X, а не Y
│   │   ├── 04_domain/      ← бизнес-логика
│   │   ├── 05_code/        ← паттерны и стиль кода
│   │   ├── 06_problems/    ← баги и обходные пути
│   │   ├── 07_context/     ← история сессий
│   │   ├── 08_people/      ← команда и роли
│   │   ├── 09_external/    ← API и сервисы
│   │   ├── 10_testing/     ← стратегии тестирования
│   │   ├── 11_deployment/  ← деплой
│   │   ├── 12_roadmap/     ← планы на будущее
│   │   └── 13_preferences/ ← ваши предпочтения
│   ├── workflows/          ← определения команд
│   └── MEMORY_INDEX.md     ← главный индекс
```

**Ключевая идея:** Всё — Markdown. Память AI можно читать, редактировать и версионировать, как обычный код.

## 🔍 Процесс поиска (RLM)

Когда задаёшь вопрос, AI не читает ВСЕ файлы памяти. Вместо этого:

```
1. EXAMINE   → Прочитать главный индекс (какие категории есть?)
2. DECOMPOSE → Выбрать 2-3 релевантные категории
3. RECURSE   → Искать файлы в этих категориях
4. AGGREGATE → Собрать находки в ответ
```

Это делает ответы **быстрыми** даже при сотнях файлов памяти.

---

## ⚠️ Важные правила

- **Один проект = один RLM-Anchor** — не используй одну `.agent/` папку на несколько проектов
- **Всегда `/sleep` перед закрытием** — иначе AI не сохранит сессию
- **Не редактируй `_index.md` вручную** — AI управляет этими файлами
- **Память дружит с Git** — коммить `.agent/` в репозиторий для командной работы

---

## 🔄 Обновление

```
/anchor_update              # обновить до последней версии
/anchor_update --check      # только проверить, не обновлять
```

Ваши данные (записи, предпочтения, история сессий) **никогда не перезаписываются** при обновлении.

---

## 🌍 Поддержка языков

RLM-Anchor работает на любом языке. Установите предпочтение в `language.md` — все ответы AI, записи и системные сообщения будут на этом языке.
