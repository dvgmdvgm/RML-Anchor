# 🧠 Система пам'яті AI (RLM-Anchor)

> **Довготривала пам'ять для AI-асистентів на основі RLM**

Персистентна система пам'яті для AI-середовищ розробки, заснована на принципах [Recursive Language Models](https://arxiv.org/abs/2512.24601) (див. [Відео-керівництво](https://www.youtube.com/watch?v=huszaaJPjU8)).

---

## 🌟 Можливості

- **📁 13 організованих категорій** — структуроване зберігання знань проекту
- **🔍 Пошук у стилі RLM** — Examine → Decompose → Recurse → Aggregate
- **🌍 Мультимовність** — відповіді та записи будь-якою мовою
- **⚡ Прості команди** — `/remember`, `/recall`, `/wakeup`, `/sleep`
- **🔄 Передача контекста** — безшовне перемикання між AI моделями
- **📝 На основі Markdown** — зручно для людей та Git
- **🔄 Збереження сесій** — контекст зберігається між сесіями

---

## 📦 Quick Start & Usage

1. **Імпортуй папку `.agent/`** у свій проект через Git:
   ```bash
   git clone --depth 1 https://github.com/dvgmdvgm/AnchorGravity.git .temp && cp -r .temp/.agent . && rm -rf .temp
   ```
2. **Встанови мову** у файлі `.agent/memory/13_preferences/language.md`.
3. **Виконай саме такий промпт:** ```/anchor_agent перевір каталоги поточного проекту на наявність даних, які допоможуть правильно вибудувати контекст і налаштувати пам'ять (технічні дані, бізнес-моделі, правила дизайну та всі інші типові шаблони для пошуку та збереження контексту проекту)``` для безпечного впровадження RLM-Anchor у поточний проект.
4. **Почни роботу** командою чату ```/wakeup```.
5. **Працюй у своїй IDE** (розробка, вирішення завдань, бізнес-рішення, роби все як зазвичай).

*У процесі роботи на важливих етапах можна використовувати* ```/remember```*, щоб зберегти важливий контекст.*

6. **Коли закінчив роботу** у своїй IDE, наприклад, перед сном, виконай команду ```/sleep```, щоб RLM-Anchor зміг зберегти твій контекст у пам'ять.

*Тепер кожного разу, коли повертаєшся до роботи над проектом, просто розбуди RLM-Anchor, запустивши* ```/wakeup```*, а в кінці сеансу знову відправ його спати* ```/sleep```*, щоб він знову запам'ятав усе, що ти робив.*

## ⚡ Команди

| Команда | Опис |
|---------|----------|
| `/wakeup` | Почати сесію, завантажити контекст |
| `/sleep` | Завершити сесію, підсумувати роботу |
| `/remember` | Зберегти інформацію в пам'ять |
| `/recall` | Знайти інформацію в пам'яті |
| `/handoff` | Створити зведення для перемикання моделі |
| `/walkthrough` | Згенерувати документацію фічі |
| `/anchor_agent` | Безпечна інтеграція в проект |
| `/memory-stats` | Показати статистику пам'яті |

## 🔄 Як це працює

### Процес у стилі RLM

```
Запит користувача
    ↓
┌─────────────────────────────────────┐
│ 1. EXAMINE — Читаємо індекс пам'яті │
│ 2. DECOMPOSE — Визначаємо категорії │
│ 3. RECURSE — Шукаємо в потрібних     │
│ 4. AGGREGATE — Об'єднуємо дані      │
└─────────────────────────────────────┘
    ↓
Контекстна відповідь (на налаштованій мові)
```
